# ♠️ DataHold’em

## 📌 Sobre o Projeto

O **DataHold’em** é um projeto de análise estatística e simulação de probabilidades aplicado ao poker Texas Hold’em.

O objetivo do projeto é calcular as chances de vitória, empate e derrota de um jogador utilizando simulações Monte Carlo, além de aplicar conceitos de probabilidade, estatística, algoritmos e ciência de dados em um problema real.

---

## 🎯 Objetivo

Transformar lógica e estatística em uma ferramenta capaz de responder perguntas como:

* Qual a probabilidade de vencer uma mão?
* Como a chance de vitória muda conforme o flop, turn e river?
* Quantos outs aumentam as chances do jogador?
* Como diferentes combinações impactam o resultado final?
* Como simulações estatísticas podem ser utilizadas em jogos de decisão?
